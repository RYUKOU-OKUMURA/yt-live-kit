# yt-live-kit

YouTube 公開ライブアーカイブから字幕を取得し、AI でチャプター（タイムライン）と切り抜き候補を生成するローカル Web UI ツールです。  
チャンネル単位での一括取り込み、ハイライトまとめ動画、縦型ショート動画の生成にも対応しています。

## 前提ソフト

| ソフト | 用途 | 備考 |
|--------|------|------|
| **Python 3.11+** | 実行環境 | pyenv 等で管理 |
| **[uv](https://github.com/astral-sh/uv)** | 依存管理・実行 | `curl -LsSf https://astral.sh/uv/install.sh \| sh` |
| **yt-dlp** | 字幕・動画取得 | **最新版推奨**（2025.02.19 以前では字幕取得失敗の実績あり） |
| **ffmpeg** | 動画切り出し | システム PATH 上に配置（切り抜き機能で使用） |
| **Codex CLI** | チャプター・候補の自動生成 | 未導入時は画面に日本語で手順が表示されます |

## セットアップ（初回のみ）

```bash
# リポジトリを clone した後
uv sync
```

`start.command` を使う場合、初回起動時に自動で `uv sync` が走ります（`.venv` がないとき）。

## 起動方法

### 非エンジニア向け（macOS・推奨）

1. **`start.command` をダブルクリック**  
   Finder でプロジェクトフォルダを開き、`start.command` をダブルクリックします。
2. **初回のみ**  
   「初回セットアップ中…」と表示されたら、完了まで待ちます（数分かかることがあります）。
3. **ブラウザが自動で開く**  
   `http://127.0.0.1:8501` にアプリ画面が表示されます。開かない場合は、ターミナルに表示される URL をブラウザのアドレスバーに貼り付けてください。
4. **終了するとき**  
   ターミナルウィンドウ（黒い画面）を **閉じる** だけで OK です。ブラウザのタブだけ閉じても、アプリはバックグラウンドで動き続ける場合があります。

#### うまく起動しないとき

| 症状 | 対処 |
|------|------|
| 「uv がインストールされていません」と出る | ターミナルで `curl -LsSf https://astral.sh/uv/install.sh \| sh` を実行し、ターミナルを再起動してから再度ダブルクリック |
| 「開発元を確認できないため開けません」 | 右クリック →「開く」→ もう一度「開く」 |
| ブラウザが開かない | ターミナルに表示された `http://127.0.0.1:8501` を手動で開く |

### 開発者・上級者向け

```bash
uv run streamlit run src/yt_live_kit/ui/app.py --server.address 127.0.0.1
```

## 日常操作

### 単本実行（タイムライン生成）

1. アプリを起動する（上記「起動方法」参照）
2. **実行** タブで **単本** を選択
3. **YouTube URL** 欄に、公開アーカイブの URL を貼り付ける  
   例: `https://www.youtube.com/watch?v=xxxxxxxxxxx`
4. **「実行」** ボタンを押す
5. 進捗が表示されます（字幕取得 → 整形 → チャプター生成 → 切り抜き候補）
6. 完了後、**タイムライン** が表示されます
7. コードブロック右上の **コピーアイコン** で概要欄用テキストをコピーし、YouTube 概要欄に貼り付ける
8. **「文字起こし全文」** を開くと、整形済み字幕の確認と **ダウンロード** ができます
9. **切り抜き候補** から区間を選び **「切り出し」** で mp4 を取得できます

### 一括処理（複数 URL）

1. **実行** タブで **一括** を選択
2. テキストエリアに URL を **1 行 1 本** で貼り付ける（`#` で始まる行はコメントとして無視）
3. **「処理済みをスキップ」** にチェックを入れると、チャプター済みの動画を飛ばします
4. **「一括実行」** を押す
5. 進捗バーとログで成功・スキップ・失敗を確認できます
6. 失敗した URL があっても、残りは継続して処理されます

### チャンネルからの一括取り込み

1. **チャンネル** タブを開く
2. **チャンネル URL / ハンドル** 欄に `@handle` などを入力する
3. 配信アーカイブの一覧が表示されます（**公開されたライブ配信アーカイブのみ**。限定公開・メンバー限定の動画は表示されません）
4. 表示は既定でキャッシュ（前回取得結果）を使います。最新の状態を取得したいときだけ **「再取得」** を押してください  
   （YouTube への問い合わせ回数を抑え、レート制限を避けるためです）
5. **「未処理のみ表示」** をオンにすると、まだ処理していない動画だけに絞り込めます
6. 取り込みたい動画にチェックを入れ（**「すべて選択」** も利用可）、**「選択した N 本を処理」** を押すと一括処理に投入されます
7. 進捗は画面上部のステータスバーで確認できます

### 処理済み一覧

1. **処理済み一覧** タブを開く
2. 過去に処理した動画（タイトル・video_id・成果物の有無）が表示されます
3. **「開く」** で、保存済みのタイムライン・全文・切り抜き候補を再表示できます

### ハイライトまとめ動画

1. 単本実行後の結果画面、または処理済み一覧から **「開く」** した結果画面で **「ハイライトまとめ動画」** の折りたたみを開く
2. **「ハイライト候補を生成」** を押すと、AI が配信の山場となる区間を提案します。既に切り抜き候補がある場合は **「切り抜き候補から選ぶ」** をオンにして、その候補をそのまま流用することもできます
3. まとめ動画に使いたい区間にチェックを入れます（**2 区間以上** を選ぶと「ハイライト動画を作成」ボタンが押せるようになります）
4. **「ハイライト動画を作成」** を押すと、選んだ区間を ffmpeg で連結したまとめ動画を生成します
5. 生成には **数分かかることがあります**。進捗は画面上部のステータスバーに表示されます
6. 完成した動画はその場でプレビューでき、生成に使った中間ファイルは自動で削除されます

### 縦型ショート動画

1. 結果画面の **「縦型ショート動画」** の折りたたみを開く
2. 区間の指定方法を 3 通りから選びます
   - 切り抜き候補から選ぶ
   - ハイライト候補から選ぶ
   - 開始・終了時刻を手入力する（`HH:MM:SS` 形式）
3. レイアウトを選びます
   - **ぼかし背景（推奨）** — 元の映像を切らずに中央に配置します
   - **中央クロップ** — 左右が切れます。話者が中央にいる配信向けです
4. 必要に応じて **「字幕を焼き込む」** をオン・オフします
5. **区間の長さは 10 秒以上 180 秒以下** である必要があります。範囲外の場合はボタンが押せません
6. **「ショートを作成」** を押すと、1080x1920 の縦型動画を生成します
7. 生成は **2 パスで再エンコードするため数十秒〜数分かかります**。進捗は画面上部のステータスバーに表示されます

### 元動画の削除（ストレージ管理）

元動画のキャッシュは、切り抜き・ハイライト・ショートを作るたびにフル解像度で保存されます。2 時間の配信 1 本で数 GB になることもあるため、不要になったら削除できます。

**1 本ずつ削除する**

1. **処理済み一覧** タブを開く
2. 各動画の行にある **「元動画を削除」** を押す（確認のうえで削除されます）

**まとめて削除する**

1. **処理済み一覧** タブの下部にある **「ストレージ」** の折りたたみを開く
2. **「容量を計算」** を押すと、合計容量と動画ごとの内訳（元動画・成果物・中間ファイルなど）が表示されます
3. **「N 日以上前の元動画をまとめて削除」** で、日数を指定して **「対象を確認」** を押すと、削除対象の件数と合計容量が表示されます。内容を確認してから実行してください

いずれの場合も、**削除されるのは元動画のキャッシュと中間ファイルだけです。チャプター・全文・切り抜き候補・切り出し済み mp4 は残ります。**

## 概要欄の定型文テンプレート

`data/_config/description_template.txt` に、`{{timeline}}` という文字列を含むテキストファイルを置くと、タイムラインを埋め込んだ概要欄用テキストを結果画面からワンクリックでコピーできるようになります。

```text
【配信タイムライン】
{{timeline}}

チャンネル登録はこちら: https://example.com
```

テンプレートを設定していない場合でも、タイムラインだけのコピーは通常どおり利用できます。

## 概要欄への反映（YouTube Data API）

処理済み一覧の **「概要欄に反映」** ボタンから、生成したチャプターを YouTube の概要欄に直接書き込めます。ネットワーク経由で YouTube Data API を呼び出すため、事前に以下のセットアップが必要です。

### セットアップ手順

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成する
2. 「APIとサービス」→「ライブラリ」から **YouTube Data API v3** を有効化する
3. 「APIとサービス」→「OAuth 同意画面」で、User Type を **外部** にして作成し、**テストユーザー** に自分の Google アカウントを追加する
4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」で、アプリケーションの種類に **デスクトップアプリ** を選んで作成する
5. 作成した OAuth クライアント ID の JSON をダウンロードし、`data/_config/client_secret.json` として配置する（`YTLK_YOUTUBE_CLIENT_SECRET` で別パスも指定可能）

### 使い方

1. **処理済み一覧** タブで、チャプターを生成済みの動画の行にある **「概要欄に反映」** を押す
2. **初回のみブラウザが自動で開き**、Google アカウントでの認証と権限の承認を求められます（承認後、認証情報は `data/_config/youtube_token.json` に保存され、以降は自動で使われます）
3. 現在の概要欄にチャプターをマージした内容がプレビュー表示されます。**この時点ではまだ YouTube 側は更新されません**
4. 内容を確認し、**「YouTube に書き込む」** を押すと概要欄が上書きされます（取り消しはできません）。誤りがある場合は **「キャンセル」** を押してください

概要欄はマーカー行（`▼ タイムライン` 〜 `▲ タイムラインここまで`）で管理されます。既にマーカーがある場合はその間だけを差し替え、前後の本文（挨拶文やリンクなど）はそのまま残ります。マーカーがまだ無い場合は、既存の概要欄の末尾に追記されます。

## ショート動画の安全な予約投稿（YouTube Data API）

生成済みショートは、動画詳細画面の **「7. YouTube 予約投稿」** から次の空き枠へ予約できます。事前に設定画面で、毎日の投稿時刻、投稿間隔、IANA timezone（既定は `Asia/Tokyo`）を保存してください。OAuth のセットアップは上記「概要欄への反映」と共通です。

この機能は **`privacyStatus=private` と未来の `publishAt` を使う予約投稿専用**です。`notifySubscribers=false` も固定です。即時公開、`public` や `unlisted` を直接指定する投稿、`publishAt` のない投稿は対象外です。公開予定日時は IANA timezone を持つ日時として現在より 10 分以上先である必要があり、YouTube へ送信するときだけ UTC の RFC 3339 `Z` 形式へ変換されます。条件を満たさない日時を即時公開へ変更することはありません。

### 予約手順と確認内容

1. 動画詳細画面で投稿する生成済みショートを選び、予約投稿のプレビューを開く
2. 確認ダイアログで、次の内容をすべて確認する
   - 実際の投稿先チャンネル ID と名称
   - 対象ファイルの絶対パス、サイズ、動画の長さ
   - タイトル、説明文の全文、タグ
   - ポリシーの timezone で表した公開予定日時と、変換後の UTC `Z` 日時
   - `privacyStatus=private` と `notifySubscribers=false`
   - Made for Kids、つまり子ども向けかどうかの選択
   - 現実と見分けにくい合成・改変コンテンツを含むかどうかの選択
   - YouTube Community Guidelines に準拠する内容であることの確認
3. Made for Kids と合成・改変コンテンツは、毎回「はい」または「いいえ」を選ぶ。既定値は推測されない
4. Community Guidelines の確認欄は既定で未チェックなので、内容を確認してチェックする
5. **「この内容で予約投稿を確定」** を押す

ダイアログを確定するまでは upload operation、投稿ジョブ、upload attempt は作られません。確定後にもチャンネル、ファイル、動画の長さ、投稿内容、予約枠、当日の attempt 残数を再検証します。プレビュー後に内容が変わった場合や予約枠が競合した場合はアップロードせず、新しいプレビューから確認し直します。

### upload attempt の上限

`videos.insert` の試行数は、実際に upload session を開始しようとした **`America/Los_Angeles` の暦日**ごとに数えます。公開予定日や予約枠の件数とは別です。成功だけでなく失敗や結果不明も 1 attempt に含まれ、事前の読み取り専用チャンネル確認は含まれません。

1 日の上限は `YTLK_VIDEO_UPLOAD_DAILY_LIMIT` で 1〜100 に設定でき、既定は 100 です。Google Cloud Console に表示されるプロジェクト固有の上限が 100 未満なら、その値を設定してください。上限到達後は同じ Los Angeles 暦日の新しい実 upload が停止します。公開予定日を変更しても当日の attempt は減りません。

```bash
export YTLK_VIDEO_UPLOAD_DAILY_LIMIT=20
```

### 結果不明と非公開ロックへの対応

通信切断、再試行上限、応答不明などでアップロード結果を確定できない場合、operation は `needs_reconciliation` になります。この状態では重複投稿を避けるため **自動再送しません**。画面に表示される operation ID、job ID、対象ファイル、チャンネルを使い、YouTube Studio で動画の有無を手動照合してください。照合後に再試行が必要な場合も、既存 operation を再送せず、新しいプレビューと確認を経て新しい operation として実行します。

API プロジェクトの状態によっては、アップロード自体が成功しても YouTube 側の非公開ロックにより予約時刻を過ぎても公開されないことがあります。画面で「非公開ロックの可能性」と表示された場合は予約投稿成功として扱わず、YouTube Studio で公開状態と `publishAt` を確認してください。コンプライアンス審査フォームの提出が必要な場合、その提出はアップロードとは別の外部操作です。提出内容を確認し、専用の明示承認を得るまで送信しません。

### 実機受け入れと自動テストの境界

自動テストは YouTube の実 API、実 upload、実公開を呼ばず、すべてモックで検証します。実機受け入れでは対象チャンネル、ファイル、投稿内容、予約日時、公開の可能性を先に提示し、次の操作ごとに別々の明示承認が必要です。

- P0 の probe upload。非公開ロックがなければ probe 動画も指定時刻に公開される可能性を含む
- 非公開ロック解消に必要な審査フォームの提出
- P3 の実予約公開

いずれか一つの承認を、ほかの操作や動画削除の承認として流用しません。

## CLI（上級者向け補助）

Web UI と同じ services 層を呼び出します。

```bash
uv run yt-live-kit version

# 単本: 一括パイプライン
uv run yt-live-kit run "https://www.youtube.com/watch?v=VIDEO_ID"

# 段階実行
uv run yt-live-kit fetch "https://www.youtube.com/watch?v=VIDEO_ID"
uv run yt-live-kit transcript VIDEO_ID
uv run yt-live-kit chapters VIDEO_ID
uv run yt-live-kit clips suggest VIDEO_ID

# 切り抜き（人が選んだ区間）
uv run yt-live-kit clips cut VIDEO_ID --start 00:03:42 --end 00:16:30 --output clip_001.mp4

# バッチ（URL 一覧ファイル、処理済みスキップ、スリープ間隔）
uv run yt-live-kit run --urls-file urls.txt --skip-existing --sleep 2
```

### チャンネル・ハイライト・ショート

```bash
# チャンネルの配信アーカイブ一覧（処理済みは行頭に "# " が付く）
uv run yt-live-kit channel @handle --limit 50
uv run yt-live-kit channel @handle --refresh        # キャッシュを無視して取り直す

# ハイライト
uv run yt-live-kit highlights suggest {video_id}
uv run yt-live-kit highlights suggest {video_id} --prompt-only   # Codex を呼ばずプロンプトだけ作る
uv run yt-live-kit highlights build {video_id} --segments 1,3,5  # 番号は 1 始まり。省略時は全区間
uv run yt-live-kit highlights build {video_id} --keep-segments   # 中間ファイルを残す

# 縦型ショート
uv run yt-live-kit short {video_id} --start 00:12:30 --end 00:13:20
uv run yt-live-kit short {video_id} --start 00:12:30 --end 00:13:20 --layout crop --no-subtitles
```

### Codex CLI 未導入時（チャプター生成のフォールバック）

1. `uv run yt-live-kit chapters VIDEO_ID --prompt-only` でプロンプトを生成
2. 生成された `data/{video_id}/prompt_chapters.txt` を Cursor チャットに貼り付け
3. 出力されたチャプター行をファイルに保存し、検証・取り込み:
   ```bash
   uv run yt-live-kit chapters VIDEO_ID --from-file /path/to/chapters.txt
   ```

### 共通オプション（run）

| オプション | 説明 |
|------------|------|
| `--data-dir` | 成果物ルート（デフォルト: `./data`） |
| `--skip-existing` | チャプター済み動画 ID をスキップ |
| `--sleep` | URL 間のスリープ秒数（デフォルト: 1 秒、`YTLK_SLEEP` でも設定可） |
| `--yt-dlp-path` | yt-dlp バイナリパス |

バッチ処理のステータスは `data/_batch/status.json` に記録されます。

## yt-dlp の更新

字幕取得に失敗する場合、まず yt-dlp を最新版に更新してください。**2025.02.19 以前** のバージョンでは字幕取得に失敗する実績があります。アプリ起動時に古いバージョンが検出されると警告が表示されます。

```bash
# pip / uv 経由
uv pip install -U yt-dlp

# Homebrew（macOS）
brew upgrade yt-dlp

# バージョン確認
yt-dlp --version
```

## 日本語字幕のフォントについて

縦型ショート動画に字幕を焼き込む際は、日本語フォントが必要です。次の優先順でフォントを探します。

1. Hiragino Sans
2. Noto Sans CJK JP
3. sans-serif（フォールバック。日本語には対応していません）

**日本語フォントが見つからない場合、字幕の文字が豆腐（□）で表示されます。** その場合は画面に日本語の警告が表示されます。

macOS 標準の環境であれば Hiragino Sans がプリインストールされているため、通常は何も設定しなくても日本語字幕が表示されます。

フォントが見つからない・別のフォントを使いたい場合は、環境変数 `YTLK_SUBTITLE_FONT` にフォント名を指定してください。

```bash
export YTLK_SUBTITLE_FONT="Noto Sans CJK JP"
```

## トラブルシュート

| 症状 | 原因と対処 |
|------|------------|
| 「字幕が取得できませんでした」 | 公開アーカイブか確認。yt-dlp を最新に更新して再実行。**自動字幕（ja / ja-orig）が無い動画は v1 対象外**（v1.5 で Whisper フォールバック予定） |
| チャプターが生成されない | Codex CLI のインストール・認証を確認。または `--prompt-only` で手動生成 |
| 切り抜き候補だけ失敗 | タイムラインは利用可能。Codex CLI または手動 JSON 保存を試す |
| 一括処理で一部失敗 | ログで失敗 URL を確認。`--skip-existing` で再実行すると成功分はスキップされる |
| yt-dlp 警告が出る | 上記「yt-dlp の更新」を実施 |
| 切り出しが失敗 | ffmpeg が PATH にあるか確認。`YTLK_FFMPEG_PATH` を設定 |
| yt-dlp が「No supported JavaScript runtime」と警告 | 字幕取得のみの用途では通常問題なし。警告を消す場合は [deno](https://deno.com/) のインストールを検討 |
| ショート動画の字幕が豆腐（□）になる | 日本語フォントが見つかっていません。上記「日本語字幕のフォントについて」を参照し、`YTLK_SUBTITLE_FONT` を設定 |
| チャンネル一覧が表示されない | 限定公開・メンバー限定の配信は対象外。`@handle` の綴りを確認し、「再取得」を試す |

## データ保存先

成果物は `data/{video_id}/` 配下に保存されます（git 管理外）。

```
data/
  _batch/
    status.json          # バッチ処理ステータス
  _jobs/
    {job_id}.json         # 実行中・完了ジョブの状態
  _channels/
    {handle}.json         # チャンネル一覧のキャッシュ
  _config/
    description_template.txt   # 概要欄の定型文（ユーザー編集）
    client_secret.json         # YouTube Data API の OAuth クライアントシークレット（ユーザー配置）
    youtube_token.json         # OAuth 認証トークン（初回認証後に自動生成）
  {video_id}/
    meta.json
    subtitles/ja.vtt
    transcript/full.txt
    transcript/compressed.txt
    chapters/chapters.md
    clips/candidates.json
    clips/source/          # 元動画キャッシュ（「元動画を削除」で削除可能）
    clips/*.mp4            # 切り出し結果
    highlights/
      segments.json         # AI が選んだハイライト区間
      output/highlight.mp4  # まとめ動画
    shorts/
      output/short_{start}_{end}.mp4   # 縦型ショート動画
```

## 環境変数

すべて `YTLK_` を接頭辞とする環境変数で設定を変更できます。ターミナルで `export` するほか、プロジェクト直下に `.env` ファイルを置いても指定できます。

| 環境変数 | 用途 | デフォルト |
|----------|------|-----------|
| `YTLK_DATA_DIR` | 成果物ルートディレクトリ | `./data` |
| `YTLK_SLEEP` | 一括処理で URL 間に空けるスリープ秒数 | `1` |
| `YTLK_YTDLP_PATH` | yt-dlp バイナリのパス | `yt-dlp` |
| `YTLK_FFMPEG_PATH` | ffmpeg バイナリのパス | `ffmpeg` |
| `YTLK_YTDLP_TIMEOUT` | yt-dlp の字幕・メタデータ取得タイムアウト秒数 | `300` |
| `YTLK_DOWNLOAD_TIMEOUT` | yt-dlp の動画本体ダウンロードタイムアウト秒数 | `3600` |
| `YTLK_FFMPEG_TIMEOUT` | ffmpeg / ffprobe のタイムアウト秒数 | `3600` |
| `YTLK_SUBTITLE_FONT` | 字幕焼き込みに使うフォント名（未指定時は自動検出） | 自動検出 |
| `YTLK_YOUTUBE_CLIENT_SECRET` | YouTube Data API の OAuth クライアントシークレット JSON のパス | `./data/_config/client_secret.json` |
