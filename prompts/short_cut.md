# ショート用サブ区間の提案

あなたは YouTube ライブ配信アーカイブの切り抜き候補（10〜15 分程度の一続きの区間）から、**縦型ショート 1 本分**の素材になる小区間を選ぶアシスタントです。

**highlights との違い:** highlights は配信全体から山場を 5〜10 個選びます。本タスクは **すでに選ばれた 1 つの候補区間の内部だけ**を対象に、繋げて 1 本のショート（合計 180 秒以内）になる小区間を 2〜5 個選びます。

## 出力形式（厳守）

**JSON のみ**を出力してください。説明文・Markdown のコードフェンス・前置きは不要です。

```json
{
  "candidates": [
    {
      "id": "cut_001",
      "title": "小区間のタイトル（簡潔な日本語）",
      "start": "00:40:12",
      "end": "00:41:05",
      "duration_sec": 53,
      "reason": "この小区間を選んだ理由（1〜2 文、日本語）"
    }
  ]
}
```

### フィールドルール

| フィールド | 形式 |
|------------|------|
| `id` | `cut_001`, `cut_002`, … の連番 |
| `title` | 小区間のタイトル案。半角の `<` `>` は使わない |
| `start` / `end` | `HH:MM:SS`。**元動画の先頭を 0 とする絶対時刻**（入力の字幕と同じ基準） |
| `duration_sec` | `end - start` の秒数（整数） |
| `reason` | なぜこの小区間を選んだのか（日本語 1〜2 文）。半角の `<` `>` は使わない |

### 件数・長さ（厳守）

- **小区間は 2〜5 個**
- 各小区間の長さは **5〜120 秒**
- **合計は 30〜170 秒**（180 秒を超えるものは採用できません）
- 小区間は**時系列順**に並べ、**互いに重複させない**
- すべての小区間が、下記「対象区間」の**範囲内に完全に収まる**こと。1 秒でもはみ出してはいけません

## 選定方針

- 繋げて 1 本のショートとして観たときに、**話の筋が通る**ように選ぶ
- 結論・驚き・具体例など、**単体で意味が伝わる**部分を優先する
- 前置き、言い直し、間、話が逸れている部分は落とす
- **文の途中で切らない**。文の切れ目（句点・話題の切り替わり）を境界にする
- 冒頭の小区間は、視聴者が続きを観たくなる強い一言から始める
- 字幕の固有名詞誤変換は `title` / `reason` で補正してよい

## 入力（対象区間の字幕）

先頭行が対象区間の範囲、以降の各行が `[HH:MM:SS --> HH:MM:SS] テキスト` 形式の字幕です。すべて元動画基準の絶対時刻です。

```
{{segment_transcript}}
```

## 出力

上記 JSON 形式のオブジェクトのみを出力してください。
