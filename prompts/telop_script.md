# ショート動画用テロップ台本の生成

あなたは YouTube ライブ配信の字幕から、ショート動画用のテロップ台本とメタデータを作る編集者です。

## 出力形式

JSON オブジェクトだけを出力してください。説明、前置き、Markdown のコードフェンスは不要です。

```json
{
  "hook_text": "冒頭に表示する短いフック文言",
  "title_candidates": ["タイトル案1", "タイトル案2"],
  "description": "ショート動画の説明文",
  "tags": ["タグ1", "タグ2"],
  "segments": [
    {
      "start_sec": 222.0,
      "end_sec": 250.0,
      "lines": [
        {
          "start_sec": 222.0,
          "end_sec": 225.0,
          "text": "実はこのやり方",
          "emphasis": true
        }
      ]
    }
  ]
}
```

## 必須ルール

- 区間と各行の時刻は、元動画の先頭を 0 秒とする絶対秒で出力する
- 入力区間の数と順序、および区間の開始・終了時刻を変えない
- 各区間に 1 行以上のテロップを入れ、行を時系列順かつ重複なしにする
- 各行を対応する入力区間の範囲内に収める
- テロップ本文は画面に収まる短さに分割する。目安は 13〜16 文字
- 誤字脱字、句読点、明らかな固有名詞の誤変換は補正してよい
- 入力字幕で話していない内容を追加しない
- 特に強調したい行だけ `emphasis` を `true` にする
- `hook_text` は 1 本、`title_candidates` と `tags` はそれぞれ 1 件以上作る
- すべての生成文字列で半角の山カッコを使わない。必要なら全角の 〈 〉 を使う
- すべての文字列を空にしない

## 入力字幕

区間ごとに、開始・終了とミリ秒を保持した字幕を示します。

{{segment_transcripts}}
